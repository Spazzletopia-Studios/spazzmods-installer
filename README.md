# SpazzMods Installer

One Windows app that installs and updates every SpazzMods module for you.
Pick your Foundry modules folder, click Install, done.

## Install

Download `SpazzModsInstaller.exe`:
https://github.com/Spazzletopia-Studios/spazzmods-installer/releases/latest

Windows SmartScreen will warn you the first time you run it — click
**More info**, then **Run anyway**. This is normal for a small app that
isn't yet widely known to Windows; the installer carries no secrets and
needs no special permissions.

## Using it

- Lists every SpazzMods module, free and premium, with your installed
  version next to the latest release.
- Free modules install with no account at all.
- Premium modules unlock after you **Sign in with Patreon** with an active
  SpazzMods Supporter membership ($10/month).
- Pick your Foundry modules folder once — the installer finds it
  automatically on most setups, or you can browse to it.
- On The Forge, Linux, or Mac (no Windows exe): sign in from a browser at
  https://spazzmods-gate.spazzletopia.workers.dev/auth/start?port=8646&state=web
  and paste your personal install links into Foundry instead.
